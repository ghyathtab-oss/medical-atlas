# MedAtlas — منصة محاضرات طبية عربية قابلة للتوسع

هذا **إصدار منصة متعددة المحاضرات** يمكن نشره على GitHub Pages دون خادم أو Node.js. تظهر المحاضرات في فهرس موحّد يستمد بياناته من `data/lectures.json`. تتضمن النسخة الأولى محاضرة RUQ مع رابط مستقل. يمكن لاحقاً إضافة محاضرات جديدة دون إعادة برمجة الواجهة.

## النشر على GitHub Pages

1. أنشئ مستودعاً **Public** باسم `medical-atlas` في GitHub (أو اختر اسماً آخر).
2. فك ضغط ملف المشروع وارفع **محتويات المجلد الداخلي** إلى جذر المستودع بحيث يظهر `index.html` بجوار `assets/` و`data/` و`lectures/` مباشرة. GitHub لا يفك ضغط ZIP تلقائياً.
3. من المستودع افتح **Settings → Pages → Build and deployment**.
4. اختر **Deploy from a branch**، ثم `main` و`/(root)`، واضغط **Save**.
5. بعد نجاح النشر، رابط المستودع `medical-atlas` سيكون عادة `https://USERNAME.github.io/medical-atlas/`.

لا ترفع ملف ZIP نفسه وحده؛ GitHub Pages يحتاج إلى ملفات HTML الفعلية. لا تحتوي هذه الحزمة على ملفات تبدأ أسماؤها بنقطة؛ ولا تحتاج إلى ملف خاص لتعطيل Jekyll لتشغيل هذا الإصدار.

## بنية المشروع

```text
index.html                      # الرئيسية + الفهرس
assets/site.css                # تصميم المنصة
assets/site.js                 # البحث والتصفية وبطاقات المحاضرات
assets/logo.svg

data/lectures.json             # بيانات المحاضرات
lectures/
  ruq-pain/
    index.html                 # المحاضرة التفاعلية الأولى
    assets/                    # ملفاتها الخاصة
    SCIENTIFIC_REVIEW_AR.md    # ملاحظات المراجعة الأولية
    original-lecture.html      # المصدر الأصلي
    manifest.webmanifest
    sw.js

templates/lecture-template/index.html
```

## إضافة محاضرة جديدة

1. انسخ `templates/lecture-template/index.html` إلى `lectures/new-topic/index.html`، أو أنشئ HTML مستقلاً بالمسار نفسه.
2. أضف كائناً جديداً إلى مصفوفة `data/lectures.json`، مستنسخاً حقول المحاضرة الأولى مع تغيير `id` و`title` و`subtitle` و`category` و`href` و`features` و`status`، واجعل رابطها `lectures/new-topic/index.html`. اترك `cover` فارغاً إذا لم يكن لديك صورة.
3. ارفع التغييرات إلى فرع `main`؛ سيُظهر الفهرس البطاقة الجديدة تلقائياً.
4. راجع محتوى المحاضرة علمياً، ووثّق تاريخ مراجعتها ومراجعها، قبل وصفها بأنها معتمدة.

## تجربة محلية

تشغيل `python -m http.server 8000` من جذر المشروع ثم زيارة `http://localhost:8000/`. لا تعمل بعض عمليات جلب JSON عند فتح الملف مباشرةً بـ `file://`.

## ملاحظات

- GitHub Pages استضافة ثابتة؛ لا تتطلب قاعدة بيانات أو عمليات بناء لهذا الإصدار.
- محاضرة RUQ خضعت لتصحيحات أولية لكنها **لم تحصل على تحكيم طبي نهائي شامل**؛ لا تستخدمها بمفردها لتوجيه قرارات مرضى فعليين.
- المخططات Mermaid والخطوط المحمّلة من CDN تحتاج إلى اتصال بالإنترنت.
- تقدم الطالب والتفضيلات محفوظة في متصفحه؛ لا يوجد نظام تسجيل حسابات أو مراقبة مركزية حالياً.
- أسماء المحتويات ومحاضراتك وحقوق النشر تخصك؛ أضف الترخيص المناسب عند النشر العلني.
